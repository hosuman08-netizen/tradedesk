How the simulation works: prices follow a seeded random walk with GARCH(1,1) volatility clustering and Poisson news shocks, and the path is a pure function of wall-clock time — so reloading resumes the same market instead of rerolling it. Within each minute the tick path is a Brownian bridge, which is why a live tab never drifts off that path. Resting orders match by price-time priority behind a real queue, which is why partial fills happen. Fees are 0.02% maker / 0.06% taker. None of it is real, and none of it is investment advice.
